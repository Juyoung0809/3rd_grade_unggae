## Phase 1. 기반 설계

## Phase P3. 운영형 외부연동 + 관측성

### 생성된 파일

#### 백엔드
- `Back/build.gradle` — spring-boot-starter-actuator, webflux 추가
- `Back/src/main/resources/application.yaml` — Toss, Actuator 설정
- `.env` — TOSS_CLIENT_KEY, TOSS_SECRET_KEY, VITE_TOSS_CLIENT_KEY 추가

**결제 모듈 (토스페이먼츠 실제 연동)**
- `Back/.../payment/entity/Payment.java` — orderId, paymentKey, PENDING/FAILED 상태 추가
- `Back/.../payment/service/TossPaymentService.java` — WebClient로 Toss API confirm/cancel 호출
- `Back/.../payment/service/PaymentService.java` — prepare(PENDING 생성), confirmToss(PG 검증+Enrollment 생성)
- `Back/.../payment/controller/PaymentController.java` — POST /api/payments/prepare, POST /api/payments/toss/confirm
- `Back/.../payment/dto/TossPrepareRequest.java`, `TossPrepareResponse.java`, `TossConfirmRequest.java`, `TossConfirmResponse.java`
- `Back/.../payment/repository/PaymentRepository.java` — findByOrderId 추가
- `Back/.../admin/service/AdminPaymentService.java` — 실제 Toss cancel API 호출
- `Back/.../enrollment/service/EnrollmentService.java` — 유료강의는 Toss 결제 후 별도 처리, 무료만 직접 등록

**스케쥴러**
- `Back/.../scheduler/SchedulerService.java` — 만료 RefreshToken 정리(매일 새벽 2시), 일별 결제 통계(매일 오전 9시), PENDING 결제 만료(매 시간)
- `Back/.../auth/repository/RefreshTokenRepository.java` — deleteByExpiresAtBefore 추가

**Webhook 수신**
- `Back/.../payment/controller/TossWebhookController.java` — POST /api/webhooks/toss (Toss 결제 상태 동기화)

**운영 로그 (관측성)**
- `Back/.../common/filter/RequestLoggingFilter.java` — MDC requestId 주입, 요청/응답 로그

**보안 강화**
- `Back/.../common/filter/XssFilter.java` — 모든 요청에 XSS 방지 Wrapper 적용
- `Back/.../common/filter/XssRequestWrapper.java` — HTML 태그/스크립트 sanitize

**공통**
- `Back/.../common/response/ErrorCode.java` — Payment 관련 에러코드 6개 추가
- `Back/.../common/security/SecurityConfig.java` — 웹훅 public, Actuator 권한 분리
- `Back/.../UnggaeApplication.java` — @EnableScheduling, @EnableAsync 추가

**배포**
- `Back/Dockerfile` — 멀티스테이지 빌드 (JDK21 → JRE21)
- `Front/Dockerfile` — 멀티스테이지 빌드 (Node → Nginx)
- `Front/nginx.conf` — SPA 라우팅, /api 프록시
- `docker-compose.yml` — MySQL + Backend + Frontend 오케스트레이션

#### 프론트엔드
- `Front/src/pages/PaymentPage.tsx` — 토스 JS SDK 결제창 연동
- `Front/src/pages/PaymentSuccessPage.tsx` — 결제 확정 API 호출 후 수강 완료
- `Front/src/pages/PaymentFailPage.tsx` — 결제 실패/취소 안내
- `Front/src/api/payments.ts` — preparePayment, confirmTossPayment API 추가
- `Front/src/App.tsx` — /payment/:courseId, /payment/success, /payment/fail 라우팅 추가

### 설계 결정
- 유료 강의 결제 흐름: prepare(PENDING 생성) → 토스 결제창 → confirm(PG 검증+Enrollment 생성)
- 무료 강의: 기존 /api/enrollments 직접 수강신청 유지
- XSS 방지: `@RequestBody` JSON은 Jackson이 처리하므로 Query Parameter/Header에 집중
- Actuator: /actuator/health, /actuator/info 공개, 나머지는 ADMIN 전용
